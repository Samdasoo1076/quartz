# 내 Obsidian 노트 공개 사이트

여기에 Obsidian 노트를 `quartz/content/` 폴더로 복사하면 자동으로 사이트가 만들어집니다.

- 이 파일(`content/index.md`)은 홈 페이지입니다. 필요에 맞게 수정하거나 교체하세요.
- 이미지/첨부 파일은 `content/` 내부의 아무 폴더에 넣어도 됩니다.
- 초안은 문서 앞머리에 `draft: true`를 넣으면 공개되지 않습니다.

빠른 시작:

1) 로컬 미리보기: 프로젝트 루트에서 `npx quartz build --serve`
2) GitHub Pages 배포: `quartz/.github/workflows/deploy.yml`를 활성화하고 `baseUrl`을 내 주소로 바꿔 커밋/푸시

즐거운 정원 가꾸기 🌱
